# Contribuindo

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Mantenha a separação entre Models, Services e interface WPF.
4. Não inclua chaves de API, arquivos pessoais ou dados da biblioteca.
5. Execute `dotnet build -c Release` no Windows antes de abrir um pull request.
6. Descreva o problema resolvido e como validar a mudança.
